Configure independent menus and hierarchical menu data for Desktop and Mobile devices with visual drag-and-drop tree editing.

== Description ==

Device Menu Manager allows WordPress store owners and developers to manage completely independent menu hierarchies for Desktop and Mobile devices.
Includes a visual nested drag-and-drop tree builder, raw JSON import/export, and integration with the Flatsome theme.

== Features ==
* 3-tier master and per-device overrides (Master, Desktop Override, Mobile Override).
* Exact JSON schema storage (db_id, title, url, menu_item_parent, classes).
* Hierarchical drag & drop tree builder with level indicators (Root, Column/Group, Sub-link).
* Instant badge selectors: HOT, NEW, FEATURED.
* Direct Raw JSON Editor with 1-click import & export.
* Pre-loaded with default HandDN collection dataset.
* Seamless Flatsome Header Builder compatibility.
