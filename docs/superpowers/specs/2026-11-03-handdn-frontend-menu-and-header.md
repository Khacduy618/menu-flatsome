# Design Spec: Handdn Frontend Header & Drawer Menu Integration

## 1. Overview & Objectives
Transform the frontend of `https://handdn.ddev.site` (Flatsome + WooCommerce) to match the luxury Handdn branding:
1. **Header Layout & Aesthetics**: Replicate the exact design provided by the user:
   - **Top bar** (dark navy `#161735`):
     - Left: Social icons (Facebook, Instagram, X/Twitter, YouTube).
     - Center: Free shipping text (*"Free shipping worldwide from $450"*).
     - Right: Quick utility links (*"Size Guide | Contact Us | Order Track"*).
   - **Main Header** (white background, height ~72px, clean borders):
     - Left: Hamburger button with 3-bar icon and uppercase "MENU" text; vertical divider `|`; square rounded search button icon.
     - Center: Centered Handdn logo (*"HANDDN Bespoke Watchstrap"*).
     - Right: Cart display (`Cart / $0.00 🛒`) with live WooCommerce cart fragments; vertical divider `|`; `Login / Register` link.
2. **Full-Featured Drawer Menu**:
   - Clicking the hamburger button (`MENU`) opens the Handdn prototype drawer menu.
   - Powered dynamically by `device-menu-manager` data (`dmm_menu_data` + drawer promo + Trustpilot footer).
   - **Desktop**: Left slide-in root panel, cascading horizontal sub-panels on click/hover, rightmost Editorial Visual banner dynamically updating with leather grain swatches or product photos.
   - **Mobile**: Full-width drill-down navigation with header back button and sub-panel feature cards.
   - Scrim background overlay, smooth cubic-bezier transitions, ESC key dismiss, keyboard accessibility.

## 2. Architecture & Components

### 2.1. Backend / Data Flow
- `DMM_Frontend_Renderer` (`includes/class-frontend-renderer.php`):
  - Traverses the hierarchical tree generated by `DMM_Menu_Data_Manager::get_active_menu_tree('desktop')`.
  - Generates HTML for:
    - Scrim overlay (`#scrim.scrim`)
    - Main Drawer container (`#hm.hm`) containing:
      - Root panel (`#p-root.hm-panel.lvl0`): Primary items, Secondary items, Promo card, Trustpilot & WooCommerce footer.
      - Child panels (`.hm-panel.lvl1`, `lvl2`...): Back button (mobile), panel title, close button, groups (`.hm-group`), headings, links, sizes grid (14–26mm), and sub-panel feature cards (`.feature`).
    - Editorial Visual Banner (`#hmVis.hm-visual`): Rightmost pane on desktop with canvas/image swatch and caption overlay.
    - Search Sheet Modal (`#srch.srch`): Full-screen search overlay with live product search form and popular suggestion tags.
- `DMM_Flatsome_Integrator` (`includes/class-flatsome-integrator.php`):
  - Hooks `DMM_Frontend_Renderer::render()` to `wp_footer`.
  - Disables Flatsome's default `#main-menu` off-canvas mobile drawer when DMM is active to avoid event conflicts.
  - Enqueues `assets/css/handdn-menu.css` and `assets/js/handdn-menu.js` on the frontend with dependencies on jQuery (for WooCommerce cart fragments if needed) and Google Font `Jost`.
  - Configures Flatsome Header Builder theme mods (logo center, topbar elements, main header elements) or filters header markup to guarantee layout consistency.

### 2.2. Frontend Assets
- `assets/css/handdn-menu.css`:
  - Prototype styling: CSS variables (`--paper`, `--ink`, `--line`, `--wash`, `--font: 'Jost'`), panel geometry, staggers, animations (`cubic-bezier(.16,1,.3,1)`).
  - Header styling:
    - `#top-bar.header-top`: Background `#161735`, text color `#ffffff`, font size 12px, flex alignment.
    - `#masthead.header-main`: White background, centered logo, left hamburger + search button, right cart + login.
    - Search button: 40x40px rounded box border `#e8e4de` / hover `#1b1714`.
    - Cart & Login: Clean typography matching Handdn aesthetic.
- `assets/js/handdn-menu.js`:
  - Complete prototype logic ported to standard frontend script:
    - Drawer open/close state machine (`isOpen`, `stack = []`).
    - Multi-panel horizontal cascading for desktop, drill-down with `.behind` for mobile.
    - Hover listeners on items to update `#hmVis` with leather swatches (canvas generated procedural grain or custom image URL) and text captions.
    - Search modal open/close controller.
    - ESC key handling (steps back one panel on mobile, or closes drawer).
    - Trap focus for accessibility.

## 3. Implementation Steps

1. **Logo & Header Setup in WordPress/Flatsome**:
   - Import `media_1793708564344_87d7ca09.png` into WordPress media library.
   - Configure Flatsome theme mods (`site_logo`, `logo_position: center`, `header_elements_left: ["menu-icon", "divider", "search"]`, `header_elements_right: ["cart", "divider", "account"]`, `topbar_elements_left: ["social"]`, `topbar_elements_center: ["html"]`, `topbar_elements_right: ["html-2"]`).
2. **Implement `DMM_Frontend_Renderer`**:
   - Class with recursive panel builder:
     - Handles `item_type: 'heading'`, `item_type: 'sizes_grid'`, `tag`.
     - Handles visual data mapping for `#hmVis` (`data-visual`).
     - Handles feature card rendering (`.feature`).
     - Handles Level 0 promo card with SVG strap silhouette.
     - Handles Trustpilot rating line and WooCommerce quick links.
3. **Frontend CSS (`assets/css/handdn-menu.css`)**:
   - Include Google Fonts `Jost:wght@300;400;500`.
   - Complete drawer CSS + Header alignment styles for Flatsome header.
4. **Frontend JS (`assets/js/handdn-menu.js`)**:
   - State management, canvas swatch texture painter (grain, scales, dots, quill, weave, smooth), hover transitions, mobile drill-down, search sheet toggle.
5. **Flatsome Integration Bridge (`class-flatsome-integrator.php`)**:
   - Enqueue assets, render drawer in `wp_footer`, override Flatsome click handler on `.menu-icon a` / `[data-open="#main-menu"]` to trigger Handdn drawer.
6. **Sync to DDEV site**:
   - `rsync` plugin files to `/Users/khacduy/Documents/project-wp/handdn/wp-content/plugins/device-menu-manager/`.
7. **Verification via PHP tests & Chrome DevTools MCP**:
   - CLI PHP test verifying rendered HTML structure.
   - MCP `navigate_page` to `https://handdn.ddev.site`.
   - MCP `take_screenshot` of header.
   - MCP `click` on "MENU", verify drawer opens, `take_screenshot`.
   - MCP `resize_page` to mobile viewport (375x812), click MENU, click "Watch Straps", verify drill-down, `take_screenshot`.
